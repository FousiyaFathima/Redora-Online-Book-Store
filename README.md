# Redora Online Book Store

Redora is a comprehensive online bookstore application designed to provide a seamless shopping experience for book lovers, combined with a unique creative space for aspiring writers. This project was developed using **Java, JSP (JavaServer Pages), and Servlets** within the NetBeans IDE environment.

## Project Overview

Redora bridges the gap between readers and writers. Beyond the standard e-commerce functionality, it features an interactive module where users can share their own stories and compete for rewards.

### Key Features

* **User Experience:**
* **Browsing & Searching:** Easily find books by title, author, or category.
* **Personalization:** Manage a personal account with "Wishlist/Favourites" and a persistent "Shopping Cart."
* **Order Management:** Streamlined checkout process and real-time order tracking.


* **Creative Module:**
* A dedicated story-writing platform for users to showcase their talent.
* Reward system integrated to incentivize creative contributions.


* **Admin Panel:**
* **Inventory Control:** Add, remove, and update book listings.
* **User Management:** Oversee registered accounts.
* **Operations:** Manage incoming orders and moderate the story-writing module, including selecting winners for creative contests.



## 🛠 Technical Stack

* **Language:** Java
* **Web Technologies:** JSP, Servlets, HTML, CSS, JavaScript
* **IDE:** NetBeans
